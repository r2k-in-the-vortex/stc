# Reference Material

This directory is for local reference documents used while writing the specification.

## IEC 61131-3:2013

Place the locally obtained IEC 61131-3:2013 PDF here. It is **not** redistributed and is excluded
from version control by the top-level `.gitignore`:

```text
/Specification/Reference/*.pdf
```

The specification in `Specification/` is original prose and grammar. It cites clause numbers for
traceability but does not reproduce the standard's text. Do not commit or publish the PDF.

## Other references

- SIMATIC AX Structured Text language reference (online, vendor documentation): syntax inspiration
  only; not a conformance target.
- Public summaries of IEC 61131-3:2025 Ed. 4: used only as design input for the project-defined
  UTF-8 extension. Ed. 4 is not available to this project and is not claimed.
